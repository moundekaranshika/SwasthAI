# 🩺 SwasthAI – Elderly Healthcare Companion  
An AI-powered healthcare assistant designed to help elderly people access medical guidance through simple conversation.  
Prototype supports text-based chat + voice responses.

---

## ⭐ Features
-- Record audio directly in the browser
-- Transcribe speech using OpenAI Whisper API
-- Generate suggestions using OpenAI GPT APIs
-- Clean UI built using Streamlit
-- Secure API key handling with environment variables (.env)
